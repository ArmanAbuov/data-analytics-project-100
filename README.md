# data_analytics_project-100

Проект: Дашборд конверсии для образовательной платформы.
Подготовить дашборд, презентацию и выводы. Все сделать в Jupyter notebook.

Before run you need:

- jupyter notebook
- pre-installed deps:
    - pandas
    - matplotlib
    - seaborn
    - requests
    - numpy
    - datetime
    - os
    - dotenv
    - itertools

To run execute:

```bash
jupyter execute charts_project.ipynb
```
